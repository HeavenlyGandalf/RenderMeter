# RenderMeter

RenderMeter — это инструмент, который помогает разработчикам понять, какой серверный шаблонизатор работает быстрее и стабильнее при реальной нагрузке.

Приложение сравнивает разные способы генерации HTML на сервере и показывает, какой из них быстрее.

---

## Что делает приложение

RenderMeter запускает одинаковые тесты для четырёх популярных шаблонизаторов:

- Handlebars  
- Mustache  
- Pug  
- EJS  

Каждый из них получает одни и те же данные и выполняет одну и ту же задачу — сгенерировать HTML. После этого приложение измеряет, сколько времени это заняло, и сравнивает результаты.

---

## Как устроено сравнение

Чтобы результаты были честными, всё работает по одинаковым правилам:

**Одинаковая среда**  
Все шаблонизаторы запускаются на Node.js сервере, без браузера и внешних факторов.

**Разогрев перед тестом**  
Перед измерением каждый шаблонизатор несколько раз запускается “вхолостую”. Это нужно, чтобы система успела оптимизировать код и результаты не были случайными.

**Много повторов**  
Каждый тест выполняется много раз. Потом считаются:
- среднее время
- минимальное и максимальное
- медианное значение

**Разные уровни сложности**  
Есть несколько типов тестов:
- простой (маленький список данных)
- средний (несколько сотен элементов)
- сложный (вложенные списки и условия)
- очень сложный (большие и глубоко вложенные структуры)

Так видно не только “кто быстрее”, но и как каждый инструмент ведёт себя при росте нагрузки.

**Одинаковые данные**  
Все шаблонизаторы работают с одним и тем же набором данных, чтобы сравнение было корректным.

---

## Режимы приложения

### Benchmark

Основной режим.

Здесь можно:
- выбрать шаблонизаторы
- выбрать уровень сложности теста
- запустить сравнение

После запуска показывается:
- таблица с результатами
- график сравнения
- краткий вывод, кто показал себя лучше

Также можно посмотреть, какой именно шаблон использовался в тесте.

---

### Playground

Режим для экспериментов.

Позволяет:
- написать свой шаблон
- сразу увидеть результат рендера
- замерить, сколько времени он выполняется

Также сохраняются предыдущие запуски, чтобы можно было сравнивать результаты между собой.

## Требования

- Docker
- Node.js 18+

---

Адреса
- Frontend: http://localhost:5173
- Backend: http://localhost:3001
- MongoDB: mongodb://localhost:27017/rendermeter

---

## Быстрый запуск

**1. MongoDB (Docker):**

```bash
docker start mongo 2>/dev/null || docker run -d --name mongo -p 27017:27017 mongo:7
```

**2. Backend** (отдельный терминал):

```bash
cd server
cp .env.example .env   # при первом запуске
npm install
npm run dev
```

**3. Frontend** (отдельный терминал):

```bash
cd client
npm install
npm run dev
```
